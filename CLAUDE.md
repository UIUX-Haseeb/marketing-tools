# Marketing Tools — notes for AI assistants

Internal Next.js 16 app for Provident Estate. Read README.md first.

- Tools live in `src/tools/<slug>/` and are registered in `src/lib/tools.ts`. Never hardcode tool lists elsewhere.
- Access = `teams` on the tool entry + user's team from the DB. `ADMIN` role sees everything.
- Server actions in `src/lib/actions/`. Always start with `requireUser()`; use `isMarketing()` / `isAdmin()` for gated actions.
- UI: Tailwind v4 + primitives in `src/components/ui`. Brand tokens in `src/app/globals.css`; rules in STYLEGUIDE.md. Keep screens simple and to the point; no heavy dashboards. Orange is an accent only.
- Prisma 7 with `@prisma/adapter-pg`; client is generated to `src/generated/prisma` (gitignored, regenerated by `npm run build`).
- Next 16 uses `src/proxy.ts` (not middleware.ts). Route params and searchParams are Promises.
